# AV1 media corpus (pointer)

48 lossless AV1 IVF files (8/10/12-bit; mono, 4:2:0, 4:2:2, 4:4:4; full and
narrow range; 32×24 and 17×13; four frames on a 1001/30000 clock, key frame
every two) that `tests/media_corpus.rs` decodes through
`media::Av1VideoDecoder` and compares with the generator's formula.

The files are binary, so they are not committed. Run the test with
`just media-corpus [dir]`.

## Provenance

Generated by `scripts/generate_av1_corpus.py` on the media branch of
imazen/zencodec PR 129 (manifest `build_commit`
`22c326da1eec7929880324b2682c83ae4dffbec4`, rustc 1.98.1). The generator
encodes with zenrav1e and checks every decoded code against the source with
rav1d-safe in strict mode. The manifest records the generator hashes, encoder
settings, and per-file source, decoded and encoded hashes.

Because zenrav1e wrote these files, they do not test the decoder
independently of imazen's encoder. `scripts/media-ffmpeg-oracle.sh` covers
that: libdav1d decodes zenrav1e's output, and libaom-encoded streams go
through the decoder.
